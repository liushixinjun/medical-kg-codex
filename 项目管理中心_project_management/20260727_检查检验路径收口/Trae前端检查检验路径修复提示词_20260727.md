## 三、必须修改的后端查询路径

请优先修改 `E:\Trae CN\AI专科知识图谱生成TraeCN\kg-test-page\server.py` 中疾病详情查询逻辑，尤其是 `TWO_HOP_DIMS` 或等价配置。

旧路径只能作为兼容回退，不得作为主查询：

```cypher
(Disease)-[:requires_exam]->(ExamItem)-[:exam_has_indicator]->(ExamObservation)
(Disease)-[:requires_lab_test]->(LabItem)-[:lab_test_has_indicator]->(LabSubitem)
```

正式主路径必须改为：

```cypher
(Disease)-[:has_exam_plan]->(ExamPlan)-[:includes_exam_item]->(ExamItem)-[:exam_item_has_observation]->(ExamObservation)
(Disease)-[:has_exam_plan]->(ExamPlan)-[:includes_lab_item]->(LabItem)-[:lab_item_has_subitem]->(LabSubitem)
```

## 四、推荐 Cypher

检查发现：

```cypher
MATCH (d:Disease {code:$code})-[:has_exam_plan]->(p:ExamPlan)
      -[:includes_exam_item]->(ei:ExamItem)
      -[:exam_item_has_observation]->(eo:ExamObservation)
RETURN DISTINCT
  eo.code AS code,
  coalesce(eo.name, eo.display_name, eo.preferred_name) AS name,
  ei.code AS parent_exam_code,
  coalesce(ei.name, ei.display_name, ei.preferred_name) AS parent_exam_name
ORDER BY name
```

检验细项：

```cypher
MATCH (d:Disease {code:$code})-[:has_exam_plan]->(p:ExamPlan)
      -[:includes_lab_item]->(li:LabItem)
      -[:lab_item_has_subitem]->(ls:LabSubitem)
RETURN DISTINCT
  ls.code AS code,
  coalesce(ls.name, ls.display_name, ls.preferred_name) AS name,
  li.code AS parent_lab_code,
  coalesce(li.name, li.display_name, li.preferred_name) AS parent_lab_name
ORDER BY name
```

## 五、前端展示要求

1. `检查发现` 和 `检验细项` 不是独立直连疾病的旧节点，必须从辅助检查方案继续下钻。
2. 若新路径查到数据，页面必须展示，不得因为旧关系为空而显示 0。
3. 若新路径确实为空，提示语使用：“图谱暂缺该类标准路径”，不要写“暂无数据”。
4. 若接口仍使用旧关系导致为空，调试页应提示：“接口仍按旧关系查询，需要切换 Schema V2.x 标准路径”。
5. 覆盖率页面不要再把它叫“完整率”。建议改为“知识覆盖率”，并注明它只是知识维度覆盖，不等于正式 CDSS 可上线。

## 六、疑似诊断和具体分型诊断覆盖率要分口径

`diagnostic_role=broad_diagnosis` 表示疑似诊断/待分型诊断，例如 AMI、心肌病。它必须展示分型入口、定义、临床表现、诊断检查、鉴别诊断、标准诊断和证据链；治疗方案只展示适用于分型前的通用内容。

`diagnostic_role=clinical_subtype` 表示具体分型诊断，例如 STEMI、NSTEMI、肥厚型心肌病。它必须展示分型专属的诊断标准明细、检查发现、检验细项、风险分层、治疗方案、具体药物/手术/治疗项目、禁忌规则、推荐陈述和证据链。

`diagnostic_role=independent_disease` 表示独立诊断，例如部分非分型疾病。按具体疾病完整展示。
